`lilypondLoader()`, imported from `astro-lilypond/loader`, accepts the following options.

## Options

### `base`

**Type:** `string | URL`  
**Required:** yes

The directory `pattern` resolves from — relative to the project root, or an absolute file URL.

### `pattern`

**Type:** `string | string[]`  
**Default:** `"**/*.{ly,ily,lilypond}"`

Glob pattern(s) matching score files, relative to `base`.

### `generateId`

**Type:** `(options: { entry: string; base: URL; header: Record<string, string> }) => string`  
**Default:** the file's path relative to `base`, with its extension stripped (e.g. `preludes/prelude-1.ly` becomes `preludes/prelude-1`).

Generates each entry's collection id. `header` is the file's parsed `\header` fields, so you can key ids off metadata instead of the file path if you'd like.

### `format`

**Type:** `"svg" | "png"`  
**Default:** `"svg"`

Same as the [integration's `format`](/reference/configuration/#format) option — the output format each score is rendered to.

### `defaults`

**Type:** `object`  
**Default:** same as the [integration's `defaults`](/reference/configuration/#defaults)

Default `crop`/`cropScale`/`resolution`/`version` settings applied to every file this loader renders. There's no per-file override (unlike a `.ly?crop` component import).

### `timeout`

**Type:** `number`  
**Default:** `60000`

Milliseconds to wait for a single `lilypond` invocation before aborting it.

### `outputDir`

**Type:** `string`  
**Default:** `"_lilypond/<collection name>"`

Directory name, relative to Astro's `publicDir`, that rendered assets are written into. Don't share this directory with another collection or with the `lilypond()` integration's own `outputDir`.

## `LilypondCollectionEntry` type

Each collection entry's `data` has the following shape:

```ts
interface LilypondCollectionEntry {
  // Rendered images
  pages: { src: string; width?: number; height?: number }[];

  // Autogenerated alt text
  alt?: string;
  
  // Header metadata
  arranger?: string;
  composer?: string;
  copyright?: string;
  dedication?: string;
  instrument?: string;
  meter?: string;
  opus?: string;
  piece?: string;
  poet?: string;
  subsubtitle?: string;
  subtitle?: string;
  tagline?: string;
  title?: string;
  
  // Everything else found in the file's \header block(s)
  extra: Record<string, string>;
}
```

Data can be passed directly to the `<LilyPond>` [component](/guides/component/) to render images:

```astro {9} title="MyScore.astro"
---
import { getEntry } from "astro:content";
import LilyPond from "astro-lilypond/component";

const entry = await getEntry("scores", "my-score");
---

<h3>{entry.data.title}</h3>
<LilyPond content={entry.data} />
```
