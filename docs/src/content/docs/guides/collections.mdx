---
title: Content Collections
description: How to expose a folder of LilyPond scores as an Astro content collection.
---

If you have a folder of `.ly` files, `lilypondLoader()` turns that folder into an [Astro content collection](https://docs.astro.build/en/guides/content-collections/). Each file becomes one entry, with header info like `title` and `composer` extracted for you.

## Defining a collection

Import `lilypondLoader` from `astro-lilypond/loader` and pass it to `defineCollection()` in your `content.config.ts`.

```ts {3,6-8}
// src/content.config.ts
import { defineCollection } from "astro:content";
import { lilypondLoader } from "astro-lilypond/loader";

export const collections = {
  scores: defineCollection({
    loader: lilypondLoader({ base: "./src/content/scores" }),
  }),
};
```

## Fetching a collection

Read the collection with `getCollection()`, then `render()` each entry:

```astro {6} title="MyScores.astro"
---
import { getCollection } from "astro:content";
import { renderAll } from "astro-lilypond";

const scores = await getCollection("scores");
const rendered = await renderAll(scores.map((score) => score.data));
---

<ul>
  {rendered.map(({ Score, meta }) => (
    <li>
      <h3>{meta.title}</h3>
      <Score />
    </li>
  ))}
</ul>
```

## Fetching a single entry

Use `getEntry()` with the collection name and an entry's id:

```astro {6} title="MyScore.astro"
---
import { getEntry } from "astro:content";
import { render } from "astro-lilypond";

const sonata = await getEntry("scores", "sonata");
const { Score } = await render(sonata.data);
---

<h3>{sonata.data.meta.title}</h3>
<Score />
```

The id is the file's path relative to `base`, minus any file extension:

| File (relative to `base`)  | Entry id                |
| --------------------------- | ----------------- |
| `sonata.ly`                  | `sonata`           |
| `preludes/prelude-1.ly`      | `preludes/prelude-1` |
| `works/op-27/moonlight.lilypond` | `works/op-27/moonlight` |

You can customize how ids are generated by setting [`generateId`](/reference/collections/#generateid) on the `lilypondLoader` config.

## Accessing metadata

Each entry's `data.meta` includes fields from your `.ly` file's `\header` such as `title`, `composer`, and `instrument`.

```astro {9-10} title="MyScore.astro"
---
import { getEntry } from "astro:content";
import { render } from "astro-lilypond";

const entry = await getEntry("scores", "my-score");
const { Score } = await render(entry.data);
---

<h3>{entry.data.meta.title}</h3>
<p>By {entry.data.meta.composer} for {entry.data.meta.instrument}</p>

<Score />
```
