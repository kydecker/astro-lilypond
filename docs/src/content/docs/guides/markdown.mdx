Once you've installed `astro-lilypond`, you can write LilyPond code inside of any Markdown file. Use a fenced code block (triple backticks) with the `lilypond`, `ly`, or `ily` language tag:

<UsageExample />

The markdown-based approach is great for small musical examples and excerpts which you want to write alongside prose. You can write your text, compose some music, and then switch back to text without leaving the file!

For longer musical examples, you may want to use the [`<Score> component`](/guides/component) instead.

## Alt text

Rendered scores get an `alt` attribute so they're accessible to screen readers.

By default, alt text is derived automatically from the `title` and `composer` fields in the score's `\header` block:

<FencedLilypond code={headerExample} />

This produces `alt="Sonata No. 14, by Ludwig van Beethoven"`. If only one of `title`/`composer` is present, alt text falls back to just the title, or `"Sheet music by {composer}"`. With neither, alt text is left empty (which marks the image as decorative, excluding it from screen readers).

### Customizing

Override the automatic alt text by setting `alt="..."` after the language tag in your fenced code block:

<FencedLilypond code={altOverrideExample} meta='alt="Moonlight Sonata"' />

## Image loading hints

Score images are plain `<img>` tags, so the browser fetches them eagerly by default. You can control that with the standard `loading`, `decoding`, and `fetchpriority` attributes, set the same way as [`alt`](#alt-text) — as `key="value"` pairs after the language tag.

Mark an off-screen score lazy so it doesn't fetch until it's about to scroll into view:

<FencedLilypond
	code={headerExample}
	meta='loading="lazy" decoding="async"'
	title="A score later in a long list"
/>

Prioritise an above-the-fold score on the critical path. `priority="true"` is a shorthand for `loading="eager" decoding="sync" fetchpriority="high"` — the same defaults Astro's `<Image>` component derives from its `priority` prop. Pass any of the three explicitly to override part of it.

<FencedLilypond
	code={headerExample}
	meta='priority="true"'
	title="An above-the-fold score"
/>

The hints apply to every page in a multi-page score. Unrecognised values are ignored, so a typo falls back to the default rather than writing a bad attribute onto the `<img>`.
